Netflix Movies and TV Shows – Data Cleaning

Project Overview
This project focuses on cleaning the Netflix Movies and TV Shows dataset using Python and Pandas.

Technologies Used
- Python
- Pandas
- NumPy
- Jupyter Notebook

Project Tasks
- Loaded and inspected the Netflix dataset.
- Identified missing values in different columns.
- Handled missing values using appropriate methods.
- Converted date_added into datetime format.
- Separated duration values and units.
- Checked data types.
- Exported the cleaned dataset into CSV format.

Dataset
Netflix Movies and TV Shows dataset from Kaggle.

Project Files
- Netflix_Data_Cleaning.ipynb
- netflix_cleaned.csv

Learning Outcomes
Learned practical data inspection, data cleaning, missing-value handling, and data preprocessing using Python and Pandas.
